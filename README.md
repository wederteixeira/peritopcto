### 📋 Checklist de Requisitos para a Posse

Para assinar o termo de posse e assumir o cargo de Perito Criminal, é necessário cumprir os seguintes requisitos:

* [x] **Escolaridade**: Diploma de conclusão de curso superior em nível de graduação na área especificada no edital[6].
* [x] **Habilitação**: Carteira Nacional de Habilitação (CNH) válida[6].
* [x] **Idade**: Mínimo de 18 anos completos na data de matrícula do Curso de Formação Profissional[7].
* [x] **Aprovação**: Habilitação em todas as 6 fases do concurso[4][5].
